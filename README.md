# Elegance Atelier Project

Build a modern, luxury high-fashion designer website with a clean, high-end editorial aesthetic.

**Brand & Business Details:**

- **Brand Name:** Maison de L'Élégance (High Fashion Atelier)

- **Location:** Agbelekale, Abule-Egba, Lagos State, Nigeria

- **Contact Phone Numbers:** 08117926084 and 08101581209

- **Primary Call to Action:** WhatsApp Order buttons on items that link directly to `https://wa.me/2348117926084` and `https://wa.me/2348101581209` with pre-filled item order messages.

**Visual Layout & Key Sections:**

1. **Top Announcement Bar:** A thin, dark top bar with uppercase text stating "WORLDWIDE SHIPPING AVAILABLE • BESPOKE HIGH FASHION". Include a top bar social/contact bar.

2. **Header & Navigation:** - Clean white background with a centered, bold luxury serif logo.

   - Navigation menu links: Home, Shop Collection, Dye Lab / Atelier, About, Contact.

   - Right corner: Search input box and a gold-accented Shopping Bag counter button.

3. **Sub-Header Banner:** A soft warm-toned banner below the header displaying text: "Explore our luxury bespoke collections crafted in Lagos State."

4. **Hero Banner:** Full-width high-fashion hero display featuring editorial apparel photos and a bold, centered overlay title reading "EXPLORE YOUR STYLE".

5. **Product Grid:** - Section Header: "FEATURED DESIGNS" centered in uppercase, spaced serif text.

   - A multi-column grid displaying high-fashion clothing items with high-quality portrait imagery, collection titles, prices in Nigerian Naira (₦), and a prominent black "Order via WhatsApp" button on each product card.

6. **Location & Contact Footer:** - Atelier location details explicitly stating "Agbelekale, Abule-Egba, Lagos State, Nigeria".

   - Clear display of contact numbers: 08117926084 and 08101581209.

7. **Floating Action Widget:** A floating green WhatsApp chat icon fixed in the bottom-right corner linking directly to `https://wa.me/2348117926084`.
